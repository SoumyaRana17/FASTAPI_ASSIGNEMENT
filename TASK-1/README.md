# Lost and Found API

## 1. Project Description

The Lost and Found API is a REST API developed using FastAPI and SQLModel.

It is used to manage lost and found items. Users can add, view, update, delete, and search items based on their status and category.

The application uses SQLite as the database.

## 2. Technologies Used

- Python
- FastAPI
- SQLModel
- Pydantic
- SQLite
